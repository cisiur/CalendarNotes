# 04 — Screens
## Navigation
Polish default UI, Android bottom nav, Windows sidebar. Four primary destinations: Kalendarz, Wpisy, Szablony, Ustawienia.
## Kalendarz
Monday-first month grid. Per-day count and optionally template dots; tap date to display notes and add new item with selected date. Month arrows and today shortcut.
## Wpisy
Date descending, grouped by day, filtered by template/date range. Show entry title/template/time and short typed-field summary. Edit or soft-delete.
## Szablony
Create, reorder, rename and archive fields; select type, required/default/choice options; preview dynamic form; templates versioned so older entries retain original semantics.
## Edytor wpisu
Date, template, dynamic typed controls, title/free text. Validation and unsaved-edit guard. Unlimited entries per date. No bedtime assumptions in code.
## Ustawienia
Local DB location/readiness, selected external exchange folder and platform access status, manual sync, pending import/export count, conflict indicator, backup and export settings. Never show cloud-delivered status unless verifiable.
## Accessibility
Keyboard shortcuts for Windows, Android touch targets >=44dp, accessible descriptions, high contrast, 24h time, responsive resizing.
